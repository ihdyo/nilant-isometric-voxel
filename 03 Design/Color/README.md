# Colour

`tailwind-v4-palette.json` is a copy of Nilant's (`../Nilant/03 Design/Color`), from the official tailwindcss@4.3.3
theme: 26 families × 11 shades (50–950), each with its OKLCH value and hex. Every colour in Voxel Fauna is a token
from this file (`orange-400`, `sky-200`): palettes and backgrounds in `animal.json`, the light rig and the type in
`vf_standards.py`. Never a raw hex in a script.
