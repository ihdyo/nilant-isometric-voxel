# Voxel Fauna — Master Production System

## 1. Project Objective

Build a reusable production system for creating a consistent collection of **isometric voxel-style animal illustrations** using Blender.

The project should establish a shared visual identity, modeling methodology, Blender rendering configuration, directory organization, documentation standards, and export workflow.

Every animal must maintain the same artistic identity while retaining its own recognizable anatomical characteristics and complementary color scheme.

The system must support continuous development across multiple sessions. Future sessions must be able to create new animals by following the established project skill and documentation, without redefining the production standards.

## 2. Confirmed Creative Direction

These decisions are established project requirements and must not be changed without explicit approval.

### Camera and orientation
- Use a three-quarter isometric view.
- Show the animal's front and side simultaneously where anatomically appropriate.
- Use a consistent camera position and projection across the collection.
- Record the exact camera configuration in the shared production skill.
- Keep the animal's entire body visible.

### Voxel geometry
- Use large, recognizable voxel blocks.
- Prioritize deliberate cubic geometry over generic low-poly modeling.
- Maintain consistent voxel scale and construction principles.
- Preserve recognizable anatomical features using block arrangements.
- Avoid excessive small blocks, noisy geometry, and unnecessary details.
- Allow controlled anatomical adjustments where required by different species.

### Animal colors
- Use soft, solid colors for voxel materials.
- Maintain a harmonious color treatment across the collection.
- Retain recognizable species-specific coloration while simplifying it into the project's visual language.
- Avoid unnecessary textures and gradients.

### Backgrounds
- Use one flat, solid background color per animal.
- Select a complementary background individually for each species.
- Ensure the animal remains visually distinct from its background.
- Do not force every animal to use the same background color.
- Avoid gradients, environmental scenery, and unnecessary decorations.

### Production workflow
- Produce one animal at a time.
- Complete the modeling, preview, documentation, and export process for that animal.
- Provide a review and approval checkpoint before proceeding to another animal.
- Never automatically start the next animal without approval.

### Required compositions
Every animal must have three illustration exports:
- 1:1 square.
- 9:16 portrait.
- 16:9 landscape.

Every animal must also have three information artwork exports:
- 1:1 square.
- 9:16 portrait.
- 16:9 landscape.

All six exports must use the same underlying animal model and established visual identity.

## 3. Establish the Reusable Voxel Animal Skill

Before producing animals, establish a project-specific skill:

`voxel-animal-production`

This skill must serve as the single source of truth for the entire Voxel Fauna project.

First inspect the existing Nilant repository and identify its established skill, documentation, and instruction locations.

Store the skill in the appropriate canonical location. If no suitable location exists, establish one following the repository's existing organizational conventions.

The skill must document:

### A. Visual standards
- Three-quarter isometric camera configuration.
- Animal orientation and presentation.
- Large voxel geometry principles.
- Voxel scale and block construction.
- Anatomical stylization.
- Material and color principles.
- Individual background selection.
- Lighting and shadow treatment.
- Subject positioning and image composition.
- Negative space and framing.

### B. Modeling standards
- Repeatable Blender modeling workflow.
- Mesh organization and naming.
- Geometry consistency.
- Material organization.
- Species-specific anatomical considerations.
- Model scale and scene organization.
- Reusable modeling scripts where appropriate.

### C. Blender rendering standards

Copy and adapt the relevant Blender 3D object requirements from the existing Nilant production system.

Inspect the actual configuration and documentation. Do not invent render parameters or replace established configurations without justification.

Maintain two profiles:

**ULTRA — Final Production**
- Highest practical visual quality.
- Detailed lighting and material rendering.
- High-quality shadows and ambient occlusion.
- Appropriate sampling and denoising.
- Clean final image output.
- Optimized for the available rendering hardware.

**LOW — Preview**
- Fast rendering for development and review.
- Reduced sampling and computational requirements.
- Simplified rendering settings where appropriate.
- Preserve the visual appearance, composition, materials, and camera configuration of ULTRA.

Both profiles must share the same scene, model, materials, and composition.

Adapt video-specific configuration to still-image production when necessary. Do not blindly copy settings that do not apply to still images.

Document the actual values used by both profiles.

### D. Cross-session consistency
The skill must include explicit instructions for future sessions:

1. Read this skill before creating or modifying any animal.
2. Inspect existing completed animal projects.
3. Reuse the established modeling and rendering configuration.
4. Follow the same voxel geometry and material standards.
5. Maintain the three-quarter isometric view.
6. Use large voxels.
7. Choose an individual complementary background for the species.
8. Produce all six required compositions.
9. Update the documentation and Excel registry.
10. Do not change established standards without documenting and approving the change.

Never rely on conversation history as the only source of production instructions.

### Biological characteristics

- Natural habitat.
- Geographic distribution.
- Native regions.
- Typical habits and behavior.
- Social structure.
- Reproduction.

### Additional information
- Unique adaptations.
- Interesting facts.
- Ecological importance.
- Role within its ecosystem.
- Other relevant species-specific information.

### Real animal photographs

Every animal project must include genuine photographs of the corresponding species.

Requirements:
- Use real photographs, never AI-generated substitutes.
- Prefer high-resolution photographs.
- Show recognizable anatomy and physical characteristics.

- Prefer public-domain or appropriately open-licensed photographs, and respect attribution and usage restrictions.

Photographs serve as references for the voxel model's anatomy, proportions, coloration, and distinctive features.

## 7. Animal Modeling and Illustration Production

Create an editable Blender project for each animal.

The model must follow the shared voxel animal skill.

### Modeling requirements
- Large voxel geometry.
- Three-quarter isometric presentation.
- Recognizable species-specific anatomy.
- Clean and deliberate mesh construction.
- Consistent material treatment.
- Soft, solid colors.
- Individual complementary solid background.

Avoid:
- Generic low-poly aesthetics.
- Excessively small voxel details.
- Randomly noisy geometry.
- Photorealistic textures.
- Unnecessary decorative objects.
- Inconsistent voxel scales.

### Illustration exports

Render three independent compositions using the same animal model.

| Composition | Aspect ratio |
|---|---|
| Square | 1:1 |
| Portrait | 9:16 |
| Landscape | 16:9 |

Adapt framing and composition independently for each aspect ratio.

Never stretch the animal or crop its anatomy to fit the required dimensions.

Keep the entire animal visible with balanced negative space.

Use LOW for previews and ULTRA for final production.

Exact output resolutions must follow the established project configuration.

## 10. Sequential Production Workflow

Follow this exact production sequence for every animal.

### Phase 1 — Research
- Identify the exact species.
- Gather reliable biological information.
- Obtain genuine animal photographs.
- Document source references.
- Identify distinctive anatomical characteristics.

### Phase 2 — Modeling
- Create the Blender project.
- Build the large-voxel animal model.
- Apply the shared visual standards.
- Configure the three-quarter isometric camera.
- Assign the individual background.
- Configure materials and lighting.

### Phase 3 — Preview and review
- Render using LOW.
- Inspect anatomy, proportions, geometry, and composition.
- Verify the entire animal is visible.
- Present the preview for review.
- Incorporate requested corrections.
- Obtain approval before final rendering.

### Phase 4 — Final production
- Render the three illustration compositions using ULTRA.
- Create the three information artworks.
- Verify the output dimensions and visual consistency.
- Save the editable Blender project.

### Phase 5 — Documentation and registry
- Complete `overview.md`.
- Complete `docs/animal-info.md`.
- Complete `docs/references.md`.
- Organize reference photographs.
- Register the image IDs in the Excel workbook.
- Verify all six final exports exist.

### Phase 6 — Completion and approval
Present the completed animal project and its six exports for review.

Do not start another animal until the current animal is approved.

## 12. Final Project Principles

The Voxel Fauna project prioritizes:

1. **Consistency:** All animals belong to the same artistic collection.
2. **Recognition:** Large voxel geometry must retain recognizable animal anatomy.
3. **Accuracy:** Biological information and animal references must be trustworthy.
4. **Reusability:** Blender scenes, scripts, and production instructions must support future animals.
5. **Maintainability:** Shared standards must be documented in one canonical skill.
6. **Controlled production:** One animal at a time, with explicit review and approval.
7. **Completeness:** Every animal has six final artworks, an editable Blender project, genuine reference photographs, biological documentation, and Excel registry entries.

The ultimate objective is to establish a scalable Voxel Fauna collection in which each new animal can be produced consistently across future sessions without losing the collection's established visual identity.
